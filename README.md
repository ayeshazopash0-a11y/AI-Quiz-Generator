

# AI Quiz Generator
### APIs & Tool Calling Assignment

## Project Overview
A Python-based quiz assistant demonstrating
function calling and structured JSON output.

## Features
- Quiz generation for Python and AI topics
- Custom generate_quiz() tool
- Structured JSON output
- Output validation
- Automatic JSON file saving
- Error handling

## Technologies
- Python 3
- JSON
- Dataclasses

## How to Run
python main.py

Choose Python or AI as the topic.

## Expected Result
The assistant calls the quiz generator,
validates the result, and saves output.json.

## Learning Outcomes
- Function calling
- JSON serialization
- Structured data validation
- Python error handling

## Note
This is a local demonstration using a
predefined question bank. It does not
call an external AI API.
